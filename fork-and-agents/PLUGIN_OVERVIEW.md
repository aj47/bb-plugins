Fork a thread from any message, and watch the background work an agent starts.

## What you get

- A **Fork from here** button on every chat message. It opens a Fork panel where you can add a first message and pick the same workspace, a new worktree, or a new personal workspace.
- A **Fork thread** entry in the side panel's new-tab list that forks at the latest turn.
- An **Agents** button in the thread header with a live count of running background work.
- A **Background agents** panel listing the thread's background tasks and workflows, every native subagent call (expand one to read its output), and bb child threads you can open.
